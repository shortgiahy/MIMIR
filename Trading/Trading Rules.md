# Trading Rules

> Hard rules. Non-negotiable.

---

## Pre-Session Requirement

Before the session opens, complete the following or do not trade:

1. Mark previous day's volume profile levels (VAH, VAL, POC)
2. Mark weekly profile levels:
   - Early in the week → use **previous week's** profile
   - Late in the week → use **current week's** profile
3. Identify potential absorption and reversal zones at key levels
4. Define the trade you're looking for before price action begins

**If pre-market setup is not completed before 7:30 AM — no trading that session.**

---

## Hard Rules

### Rule 1 — One trade per session
One trade taken, then session is over — win or lose. If you miss valid setups before taking a trade, keep waiting. Once a trade is taken, platform closes.

This forces selectivity. You cannot overtrade. You cannot revenge trade. There is nothing to chase.

### Rule 2 — Strategy lock
Only **absorption** and **reversal** trades at key volume profile levels.

Breakouts do not exist. If the setup is not absorption or reversal — it is not a trade.

### Rule 3 — Position sizing
Max risk: **$250 per trade.** Set before entry. Never adjusted intra-session.

| Stop distance | Contracts |
|--------------|-----------|
| ~$125 | 2 contracts |
| ~$200 | 1 contract |

### Rule 4 — Target
$600–$1,200 target based on the opposite side of the value area or POC. Target is defined **before entry**, not after.

### Rule 5 — Missed trade protocol
If you identify a valid setup and miss it (hesitation or bad fill):
- Mark it as a valid miss
- Move on and wait for the next valid setup
- It is not FOMO fuel — it is a trade that passed

### Rule 6 — FOMO kill switch
If you want a trade *because you missed the last one* rather than because the setup is valid — session is over. Close the platform immediately. Log it.

There is no exception to this rule.

### Rule 7 — Copy trade acknowledgment
Before every entry, state out loud or in writing: **"This is on all accounts."**

One trade is a multi-account event. One bad entry does not affect one account.

---

## Why These Rules Exist

The accounts blew because:
1. Two valid setups were missed (hesitation + bad fill)
2. FOMO triggered
3. A breakout trade was taken — outside the defined edge
4. Size control broke down under emotional pressure
5. All accounts blew simultaneously within one hour

These rules are designed so that sequence is impossible to repeat:
- Rule 2 makes the breakout trade illegal
- Rule 1 makes revenge trading structurally impossible after a loss
- Rule 6 kills the session the moment FOMO is recognized
- Rule 3 locks size before emotions enter the picture
- Rule 7 forces awareness of the multi-account stakes before every entry
