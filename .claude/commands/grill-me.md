# /grill-me — Structured Interrogation

Run a structured interrogation on the topic or decision provided as `$ARGUMENTS` before any plan is proposed or action taken.

---

## When This Runs

Before acting on any:
- Major life or career move
- New project definition or scope
- System design (schedules, workflows, protocols)
- Any decision where acting before full understanding would waste significant effort

Do not skip this to be fast. A bad plan executed quickly is worse than a good plan executed late.

---

## The Grill

Ask pointed questions — one at a time or in a tight batch, not a questionnaire dump — until each of these five is sharp, not vague:

1. **The actual goal** — not the stated goal, the real one underneath it
2. **Constraints** — time, money, energy, dependencies
3. **Success criteria** — how will we know it worked?
4. **Failure modes** — what kills this before it starts?
5. **Tradeoffs** — what does choosing this cost elsewhere (schedule, other projects, Natalie time, decompression)?

Challenge vague or hedged answers directly — "that's not an answer, that's a placeholder." The grill is not done until the answers are sharp enough to act on.

---

## Output

Close with:
- A concrete problem statement (1–2 sentences)
- A recommended first action — one direction, with reasoning. No "here are three options" unless the tradeoffs are genuinely close.

If the topic touches a tracked project or decision, log the outcome to the relevant file (`System/Brain.md`, `System/Loose Ends.md`, or the project's own notes) rather than leaving it chat-only.

---

## Example

```
/grill-me I want to start building the Baymax robot
```
