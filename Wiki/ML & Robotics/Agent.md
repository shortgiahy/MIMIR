# Agent

**One-liner:** The learner and decision-maker in reinforcement learning — the entity that observes states, chooses actions, and optimizes cumulative reward over time.

## Core Idea
$$\pi^* = \arg\max_\pi \mathbb{E}_\pi\left[\sum_{t=0}^{\infty} \gamma^t r_t\right]$$
The agent's goal is to find the optimal [[Policy]] π* that maximizes expected discounted cumulative reward. At each timestep t the agent receives state s_t from the [[Environment]], selects action a_t according to its policy, and receives scalar feedback r_t. This loop — observe, act, receive reward, repeat — is the entire RL paradigm.

## Why It Exists
Supervised learning assumes a human-labeled dataset of (input, correct output) pairs. For many problems — game playing, robot locomotion, dialogue — the correct output is unknown or too costly to label. The agent framework allows learning from interaction: the agent discovers good behavior by trying things and observing consequences, without ever needing a labeled dataset of correct actions.

## Real-World Applications
- **AlphaGo / AlphaZero:** A single agent that learns to play Go (or chess, shogi) purely by playing against itself. The "supervisor" is the win/loss signal.
- **ChatGPT (RLHF):** A language model agent that generates text, receives a reward from a human preference model, and is updated via PPO to generate preferred responses.
- **Robot locomotion (Isaac Sim):** A legged robot agent controlling 12 joint torques simultaneously, learning to walk by receiving reward for forward velocity and penalties for falling.
- **Baymax navigation:** An agent that observes LiDAR + camera inputs, selects velocity commands, and is rewarded for reaching goal positions without collisions.
- **Atari DQN (DeepMind):** An agent with raw pixel input that learned superhuman play across 49 games using only the game score as reward.

## Intuition
In supervised learning the model is a passive function approximator: it maps inputs to outputs that a teacher dictates. The agent is fundamentally different — it is an **actor in a causal loop**. Its actions change the [[Environment]], which changes the [[State]] it observes next. This causal feedback means the agent must think about long-term consequences, not just immediate correctness.

Contrast with supervised learning:
| Property | Supervised | Agent (RL) |
|---|---|---|
| Feedback | Label per input | Scalar reward per action |
| Data | Fixed dataset | Generated by own behavior |
| Goal | Minimize prediction error | Maximize cumulative reward |
| Causality | Actions don't change data | Actions change next observation |

The agent encapsulates three things: a [[Policy]] (what to do), optionally a [[Value Function]] (how good is this state), and optionally a model of the environment (what will happen next). These can be represented as neural networks, tables, or any function approximator.

## Derivation
The agent's optimization objective — the expected return — is defined as:

$$G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}$$

where γ ∈ [0,1) is the discount factor. The agent seeks policy π that maximizes E[G_0].

The agent interacts with the environment as a Markov Decision Process (MDP). At each step:
1. Agent observes s_t
2. Agent samples a_t ~ π(·|s_t)
3. Environment transitions: s_{t+1} ~ P(·|s_t, a_t)
4. Agent receives r_t = R(s_t, a_t, s_{t+1})

The policy gradient theorem gives the gradient of the objective with respect to policy parameters θ:

$$\nabla_\theta J(\theta) = \mathbb{E}_\pi\left[\nabla_\theta \log \pi_\theta(a_t|s_t) \cdot G_t\right]$$

The agent uses this gradient (or an estimate from [[Stochastic Gradient Descent]]) to update its [[Policy]] toward higher-reward behavior.

## Worked Example
```python
import numpy as np

# Minimal tabular agent on a simple grid world
# States: 0..4 (1D grid), Actions: 0=left, 1=right
# Goal: reach state 4 (rightmost), reward +1 there, 0 elsewhere
# This is Q-learning — the agent learns a value for each (state, action) pair

n_states, n_actions = 5, 2
Q = np.zeros((n_states, n_actions))   # agent's learned value table
alpha, gamma, epsilon = 0.5, 0.9, 0.1

def step(state, action):
    """Minimal 1D grid environment."""
    next_state = max(0, min(4, state + (1 if action == 1 else -1)))
    reward = 1.0 if next_state == 4 else 0.0
    done = next_state == 4
    return next_state, reward, done

rng = np.random.default_rng(0)

for episode in range(500):
    state = 0                          # agent always starts at left
    for _ in range(50):
        # Epsilon-greedy action selection (exploration vs exploitation)
        if rng.random() < epsilon:
            action = rng.integers(n_actions)      # explore
        else:
            action = np.argmax(Q[state])           # exploit best known

        next_state, reward, done = step(state, action)

        # Q-learning update (Bellman equation)
        Q[state, action] += alpha * (
            reward + gamma * np.max(Q[next_state]) - Q[state, action]
        )
        state = next_state
        if done:
            break

print("Learned Q-table:")
print(Q.round(3))
print("Greedy policy (0=left,1=right):", np.argmax(Q, axis=1))
# Should show: agent always goes right (action=1) from any state
```
