# Skill — /grill-me

**Trigger:** `/grill-me` (or MIMIR invokes it proactively)
**Type:** Personal skill (server-side)

---

## What It Does

A structured interrogation for large-scale projects or major decisions. Forces full clarification before any action is taken — eliminates the "start fast, course-correct constantly" failure mode.

---

## When MIMIR Uses It

MIMIR invokes this **before acting** on any:
- Major life or career move
- New project definition or scope
- System design (schedules, workflows, protocols)
- Any task where acting before full understanding would waste significant effort

Do not skip this to be fast. A bad plan executed quickly is worse than a good plan executed late.

---

## What It Does

Runs a series of pointed questions to establish:
1. **The actual goal** — not the stated goal, the real one
2. **Constraints** — time, money, energy, dependencies
3. **Success criteria** — how will we know it worked?
4. **Failure modes** — what kills this before it starts?
5. **Tradeoffs** — what does choosing this cost elsewhere?

MIMIR challenges vague answers. The grill is not done until the answers are sharp.

---

## Output

A concrete problem statement + recommended first action. No wishy-washy "here are some options." One direction, with reasoning.

---

## Example

```
/grill-me I want to start building the Baymax robot
```
